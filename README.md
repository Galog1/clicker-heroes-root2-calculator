# Clicker Heroes Root 2 Calculator

A calculator for the **root2** mod of Clicker Heroes. Paste your exported save and it gives you:

- **Ancients:** optimal levels for your hero souls, with a one-click prelevelled save to import.
- **Outsider planner:** recommended Outsider levels for your ancient souls, end-of-run estimates and a build code.

Everything runs in your browser. Your save is never uploaded anywhere.

**Use it:** https://galog1.github.io/clicker-heroes-root2-calculator/

## How to use

1. In game: Settings, then Export save.
2. Paste the save into the calculator (or open the file).
3. Use the levels shown, or click **Export a prelevelled save** and import the copied save in game (Settings, then Import save). Back up your current save first.

## Rules used

- **Ancients:** graceoflives' Ancient Calculator rules for v1.0e10 (March 2018), with the level caps on the skill ancients (Atman, Bubos, Chronos, Dogcog, Dora, Fortuna, Kumawakamaru) removed for root2.
- **Outsiders:** driej's Outsider Recommender for root2.
